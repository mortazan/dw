# DayFlow

اپلیکیشن فارسی مدیریت کارهای روزانه با Flutter.

## امکانات

- داشبورد با کارت‌های آمار، نمودار پیشرفت هفتگی و توزیع دسته‌بندی‌ها
- رابط راست‌به‌چپ فارسی با فونت Vazirmatn و تقویم کامل شمسی
- افزودن، ویرایش، حذف، ستاره‌دار کردن (مهم) و انجام‌شده‌کردن کارها
- دسته‌بندی‌ها، صفحه همه کارها با فیلتر، جستجو و اعلان‌ها (کارهای عقب‌افتاده و یادآورها)
- یادداشت متنی، تصویر و یادداشت صوتی (ضبط و پخش)
- یادآور واقعی (اعلان زمان‌بندی‌شده؛ زمان اعلان ممکن است چند دقیقه تقریبی باشد)
- کارهای تکرارشونده (روزانه، هفتگی، ماهانه شمسی): با انجام‌شدن هر کار، نوبت بعدی ساخته می‌شود
- زیرکار (چک‌لیست) با نوار پیشرفت
- پشتیبان‌گیری JSON (کپی متن) و بازیابی؛ تصویر و صدا در پشتیبان نیست
- حالت روشن، تاریک و سیستم
- ذخیره محلی روی دستگاه

## قرار دادن در GitHub

```bash
cd DayFlow-Complete
git init -b main
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/<USER>/<REPO>.git
git push -u origin main
```

پوشه مخفی `.github` را با آپلود از وب فراموش نکنید؛ استفاده از `git push` ساده‌تر است.
بعد از push به تب **Actions** بروید؛ workflow با نام **Build DayFlow APK** اجرا می‌شود و
فایل `DayFlow-Android-APK` در بخش **Artifacts** قرار می‌گیرد.

## ساخت محلی

```bash
flutter pub get
flutter analyze
flutter build apk --release
```

خروجی: `build/app/outputs/flutter-apk/app-release.apk`

## محدودیت‌ها

- تصویر پروفایل ندارد؛ به‌جای آن حرف اول نام نمایش داده می‌شود.
- داده‌ها فقط روی همان دستگاه ذخیره می‌شوند.
- APK فعلی با امضای debug ساخته می‌شود. برای انتشار عمومی کلید release اختصاصی بسازید
  و آن را (`key.properties`, `*.jks`) هرگز در Git قرار ندهید.
