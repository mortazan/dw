# مدیریت زمان (DayFlow)

اپلیکیشن فارسی مدیریت کارهای روزانه با Flutter.

## امکانات

- داشبورد: سلام با تاریخ روز، اسلایدر آهنگ/ویدیو/لینک دلخواه (قابل ویرایش)، کارت‌های آمار فشرده (کلیک = لیست کارها)، روزهای باقی‌مانده هفته با تعداد کارها، نمودار پیشرفت هفتگی و توزیع دسته‌بندی‌ها
- رابط راست‌به‌چپ فارسی، فونت Vazirmatn، تقویم کامل شمسی با نوار هفته، حالت روشن/تاریک
- کارها: افزودن، ویرایش، سوایپ برای انجام/حذف، «بازگردانی» بعد از حذف، ستاره، سه سطح اولویت، برچسب، زیرکار، تکرار (روزانه/هفتگی/ماهانه شمسی)
- دسته‌بندی‌های قابل‌ویرایش (نام، رنگ، آیکون)
- یادآور واقعی: زمان دلخواه و چند یادآور قبل از موعد (همان لحظه، ۱۰ دقیقه، ۳۰ دقیقه، ۱ ساعت، ۱ روز) و «۱۰ دقیقه بعد» روی خود اعلان
- اعلان صبحگاهی: خلاصه کارهای امروز در ساعت دلخواه
- تایمر تمرکز (پومودورو) با ثبت جلسه‌ها روی کار
- ویجت صفحه اصلی اندروید: کارهای امروز
- یادداشت متنی، تصویر و صوتی؛ پشتیبان‌گیری JSON (کپی و بازیابی)
- ذخیره محلی روی دستگاه

## قرار دادن در GitHub

```bash
cd DayFlow-Complete
git init -b main
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/<USER>/<REPO>.git
git push -u origin main
```

پوشه مخفی `.github` را با آپلود از وب فراموش نکنید؛ استفاده از `git push` ساده‌تر است.
بعد از push به تب **Actions** بروید؛ workflow با نام **Build DayFlow APK** اجرا می‌شود و
فایل `DayFlow-Android-APK` در بخش **Artifacts** قرار می‌گیرد.

## ساخت محلی

```bash
flutter pub get
flutter analyze
flutter build apk --release
```

خروجی: `build/app/outputs/flutter-apk/app-release.apk`

## محدودیت‌ها

- جابه‌جایی کارها با کشیدن (تغییر ترتیب دستی) پیاده نشده، چون لیست‌ها بر اساس زمان مرتب می‌شوند.
- اعلان صبحگاهی برای دو هفته آینده زمان‌بندی می‌شود و با هر تغییر کارها دوباره ساخته می‌شود.
- فایل‌های آهنگ و ویدیو داخل حافظه اپ کپی می‌شوند و در پشتیبان JSON نیستند.
- داده‌ها فقط روی همان دستگاه ذخیره می‌شوند.
- APK فعلی با امضای debug ساخته می‌شود. برای انتشار عمومی کلید release اختصاصی بسازید
  و آن را (`key.properties`, `*.jks`) هرگز در Git قرار ندهید.
